
# Car Dealership Review Application

## Repository Name
django-react-car-dealership

## Project Name
Car Dealership Review Application

## Project Description
This project is a full-stack Car Dealership Review
Application developed using Django and React.

The application is designed to allow users to:
- Browse car dealerships
- View dealership details and reviews
- Register and log in
- Submit reviews for dealerships
- Search dealerships by state

## Technologies
- Python
- Django
- React
- JavaScript
- HTML and CSS
- REST API
- GitHub Actions
